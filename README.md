Entry for the make.fun bounty **Monday, Reviewed in One Line** ($2, top 5 paid).

A single line, under 200 characters — the funniest one-line review of my own Monday, with concrete details and the punch landing at the end:

> Monday review: my inbox doubled, my coffee went cold, and my to-do list had babies before lunch. One star — would not recommend the week.

## Run

```sh
node main.ts
```

The program writes the entry to `/output/entry.txt` and validates the bounty gate itself: UTF-8 text, 1–200 characters, not only whitespace, exactly one line. No network, no dependencies.
